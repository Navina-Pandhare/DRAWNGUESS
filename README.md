# DRAWNGUESS

Inspired by Google's AI Experiment-Quick Draw, a CNN-based drawing recognition game built using Python and Deep Learning.

## Project Overview
DrawnGuess is an interactive game where users draw simple sketches, and a trained Convolutional Neural Network (CNN) predicts what the drawing represents in real time.

## Technologies Used
- Python
- TensorFlow / Keras
- NumPy
- OpenCV
